# Side shields
This folder contains side shieldings for FilaCab, with the goal of reducing air leaks (as defined by unexpected humidity rise from outside factor).
## Left and right sides
They both use specific sets of `side_bracket_bl_X2.stl` and `side_bracket_br_X2.stl` while using a set of `side_bracket_tl_br_X4.stl` and `side_bracket_bl_tr_X4.stl`. They are mounted per side.
## Back side
This side uses two sets of `side_bracket_tl_br_X4.stl` and `side_bracket_bl_tr_X4.stl`, mounted on the back corners.
